# cvpa has moved

The cvpa R package is now developed in the
[cvpa_dataset](https://github.com/lucasjacklucas/cvpa_dataset) repository,
alongside the data and the [policy-attitudes app](https://policyattitudes.ca/app/),
in the `rpkg/` folder. Please file issues and pull requests there.

To install the development version from GitHub:

```r
# install.packages("remotes")
remotes::install_github("lucasjacklucas/cvpa_dataset", subdir = "rpkg")
```

This repository is no longer updated; its history is kept for reference.
